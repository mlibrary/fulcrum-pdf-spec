# Fulcrum PDF Specification
The Fulcrum PDF Specification is designed to help ebook production vendors and publishers create PDF ebook files compatible with the Fulcrum platform's Reading System and conform to [WCAG AA](https://www.w3.org/WAI/WCAG2AA-Conformance) and [PDF/UA](https://pdfa.org/iso-14289-2-pdfua-2/) Accessibility requirements.
